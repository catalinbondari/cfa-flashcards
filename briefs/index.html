Paper 1 brief — read before Session 1

Ethics · Quant · Economics · FSA · Corporate Issuers. 10 minutes. Read, don't study.

Pace: minutes used = Q# × 1.5 → Q30 @ 0:45 used (1:30 left) · Q60 @ 1:30 used (0:45 left) · Q90 @ 2:05 used (0:10 left). Over 2.5 min on one Q → flag, guess, move.
Before every answer: circle LEAST / NOT / EXCEPT · name the formula before touching numbers (extra data = trap) · answer exactly what's asked · cheap calc → compute all three options.

Ethics

  • Judge the action, never the outcome.
  • "Only X" vs "both" → both is usually right.
  • LEAST likely a violation → find the clean option.
  • Best practice ≠ minimum required — read which one is asked.
  • Count every violation in "how many" questions.
  • Notice ≠ consent. Disclosure ≠ permission.
  • Referral fees: disclose before the agreement.
  • Soft dollars must benefit those clients.
  • Name the Standard by what happened, not by keywords.
  • Watch one swapped word: staff↔clients, must↔may, fair↔equal.

Quant

  • Sample σ² ÷ (n − 1). CV = σ / mean.
  • Cov = ρ σA σB · ρ = Cov / (σAσB).
  • Correlation t = r√(n − 2) / √(1 − r²).
  • χ² = (n − 1)s² / σ0² — square BOTH, use n − 1.
  • Two variances → F = s1² / s2² (bigger on top). Means → t.
  • Independence table df = (r − 1)(c − 1).
  • Type I = reject a true H0 (α). Type II = keep a false H0. Power = 1 − β.
  • b1 = Cov(X,Y) / Var(X). R² = SSR / SST. SEE = √(SSE / (n − 2)).
  • F = MSR / MSE. t = (b1 − B1) / sb1 — test vs the stated value, not always 0.
  • Prediction interval Ŷ ± tc × sf — don't skip × tc.
  • Log model → un-log with ex.
  • LINE: Linear · Independent residuals · Normal residuals · Equal variance. X and Y need NOT be normal.
  • "X explains Y" — Y is the dependent variable.

Economics

  • Cross rate: common currency in the same spot → divide; opposite spots → multiply.
  • Forward: F = S × (1 + iprice) / (1 + ibase).
  • Base currency = the "1" (after the slash in A/B).
  • Cycle: Recovery → Expansion → Slowdown → Contraction. Overtime before hiring = recovery; cut overtime then layoffs = contraction.
  • ~2% target, not 0% → buffer against deflation / zero rates.

FSA

  • FCFF = CFO + Int(1 − t) − FCInv (give interest back).
  • FCFE = CFO − FCInv + net borrowing. CFO already holds non-cash + WC.
  • Diluted EPS: + convertible pref divs, + bond interest × (1 − t); TSM shares = n(P − X)/P; skip if antidilutive.
  • Tax expense = payable + ΔDTL − ΔDTA.
  • Payable > expense (taxman bigger) → DTA.
  • DTL not expected to reverse → equity.
  • ROE = NPM × TAT × leverage (5-way: × tax burden × interest burden × EBIT margin).
  • Rising prices, FIFO ("Fat Slow Taxpayer"): higher inventory, NI, equity, taxes; lower COGS, lower D/E, lower CFO.
  • LIFO → FIFO: inventory + reserve; COGS − Δreserve.
  • Impairment reversal: IFRS yes (not goodwill); US GAAP held for use never, held for sale yes.
  • Leases: everyone 2 lines (amortisation + interest) except US GAAP operating = 1 line.
  • Gain on sale: subtract in CFO (indirect); proceeds in CFI.
  • US GAAP: interest paid/received + dividends received = CFO; dividends paid = CFF.

Corporate Issuers

  • WACC = wdrd(1 − t) + wprp + were (marginal tax rate).
  • Mutually exclusive → pick the higher NPV. Never "both", never highest IRR.
  • Perpetuity IRR = CF / cost. Sunk costs out; cannibalisation in.
  • Real options: timing · sizing (abandon / expand) · flexibility · fundamental.
  • MM no tax: WACC flat · MM tax: WACC falls, 100% debt · trade-off: U-shape. Pecking order: own cash → debt → equity.
  • Liquidity: credit lines + trade credit = primary; selling assets / renegotiating / bankruptcy = secondary.
  • Drag = slow inflows (receivables); pull = faster outflows (paying early).
  • CCC = DOH + DSO − DPO.

Paper 2 brief — read before Session 2

Portfolio · Equity · Fixed Income · Derivatives · Alternatives.

Long or short? Write three words in the margin: who am I · what do I have · what hurts me → take the side that wins from it.
Own it / receive it → SHORT. Owe it / need it → LONG. Currency long/short = the base ("1") currency.

Portfolio management

  • U = E(R) − ½Aσ² (decimals). Risk-free σ = 0 → U = rf.
  • Sharpe = (Rp − Rf)/σp · Treynor = (Rp − Rf)/βp.
  • M² = Rf + Sharpe × σm → compare with Rm, never Rp.
  • Jensen α = Rp − [Rf + β(Rm − Rf)].
  • β = Cov/σm² = ρσi/σm.
  • σp = √(w₁²σ₁² + w₂²σ₂² + 2w₁w₂ρσ₁σ₂) — don't forget √.
  • Slopes: CML = market Sharpe · SML = Rm − Rf · SCL = β.
  • Market expectations change → frontier moves. Client changes → indifference curves move.
  • Optimal risky portfolio = one tangency point on the frontier.
  • Process: Plan (IPS, benchmark) → Execute (allocation, security analysis) → Feedback.
  • DC: employee bears investment + inflation risk. Board sets risk appetite; management allocates.

Equity

  • Gordon V0 = D1/(r − g); D1 = D0(1 + g). Beta given → r from CAPM first.
  • Justified forward P/E = payout/(r − g). Retention given → payout = 1 − retention.
  • Two-stage: Guinness Stout Goes Down — Grow, Step to Dn+1, Gordon Vn, Discount Vn with Dn over n years.
  • Preferred = D / r. Count growth phases literally (high → transition → mature = three-stage).
  • Price-return index ignores dividends; total return adds them.
  • Dealer trades from its own inventory; broker finds the other side.
  • Execution = how · validity = when · clearing = settle.
  • Bond issuer = short. Fragmented industry = price competition.

Fixed income

  • Accrued = coupon × t/T (30/360: annual T = 360, semi T = 180).
  • ModDur = MacDur/(1 + y/m). Periods → ÷ m to annualise.
  • Money duration = ModDur × full price (× position). PVBP = MoneyDur × 0.0001.
  • %ΔP ≈ −ModDur × Δy + ½ × Convexity × (Δy)².
  • Approx ModDur = (PV₋ − PV₊) ÷ (2 × Δy × PV₀). Δy = actual move (75bp = 0.0075); PV₀ = current price, not par.
  • Money market rates: DR = Year/Days × (FV − PV)/FV; AOR = Year/Days × (FV − PV)/PV. Discount = Face, Add-on = Actual paid.
  • Money market price: discount PV = FV(1 − Days/Year × DR); add-on PV = FV ÷ (1 + Days/Year × AOR).
  • Money market BEY: discount → PV = FV(1 − Days/360 × DR); BEY = 365/Days × (FV − PV)/PV. Not ICONV. BEY > DR.
  • FRN discount margin: PMT = (MRR + QM)×100/m → CPT I/Y = r → DM = r×m − MRR (negative MRR: add it back). Price > par → DM < QM.
  • Approx Convexity = (PV₋ + PV₊ − 2PV₀) ÷ ((Δy)² × PV₀). The 2 is in the TOP, minus 2PV₀; bottom is Δy squared × PV₀.
  • (1 + S2)² = (1 + S1)(1 + f). Semi-annual → use periods, then × 2.
  • Implied spot = geometric mean of the one-year forwards.
  • Expected loss = PD × (1 − RR). Spread ≥ EL → adequately paid.
  • FRN: rate set at the start, paid at the end (taxi fare).
  • Losses climb: equity → subordinated → senior unsecured (pro rata) → secured.
  • Callable = negative convexity. Longer maturity = more duration.
  • Flight to quality → HY spreads widen most.

Derivatives

  • FRA: borrower long, lender short. 6×12 = starts month 6, ends month 12 (6-month rate).
  • Odd size or odd date → forward, not futures.
  • C − P = S − PV(X). Stock + short forward = risk-free bond; bills + long forward = equity.
  • Synthetic long (C − P) = stock bought with borrowed money.
  • Swap = off-market forwards whose values sum to 0.
  • π = (1 + r − d)/(u − d); value = [π·up + (1 − π)·down]/(1 + r).
  • Volatility and time help both calls and puts (time value only). r ↑ and dividends ↓ help calls.
  • Forward price fixed; value starts at 0 and moves.

Alternatives

  • Fees: read the order — management fee on end AUM; incentive net of it or independent; hard hurdle = fee only on the excess.
  • High-water mark is per LP.
  • Backwardation (spot > futures) = positive roll for longs.
  • REIT shares trade at a premium/discount to NAV.
  • Equity hedge = market neutral, long/short, value, growth, short-biased. VC = any stage.
  • PE/HF indexes overstate returns (self-reporting, survivorship).
